# Материалы для согласования платежей

Дата редакции документов: **4 октября 2026 года**. Название: **Кукареку Онлайн**.

Публичные страницы, не требующие входа:

- `/privacy` — Политика конфиденциальности.
- `/terms` — Пользовательское соглашение.
- `/support` — рабочая тикет-система поддержки.
- `/pricing` — актуальные предложения из `/api/v1/tariffs`.

Постоянные ссылки находятся внизу публичных страниц, входа/регистрации и кабинета. **Кодовое слово `PLAT` размещено там же, в строке «Код проверки: PLAT».** После регистрации кассы удалите значение `approvalCode` в `src/config/project.ts` (оставьте пустую строку); сами документы и поддержку оставьте доступными.

Использованы как образец структуры предоставленные шаблоны:

- https://telegra.ph/Politika-konfidencialnosti-08-01-83
- https://telegra.ph/Polzovatelskoe-soglashenie-08-01-39

Тексты адаптированы к реальной услуге и данным приложения. Условия о безусловном отказе в возврате, обязательном обращении за 24 часа и запрете обращения в банк из шаблона не переносились. Онлайн-оплата пока недоступна; документы это отражают. При включении платежей необходимо обновить сведения о провайдере, активации услуги и условиях оплаты. Одобрение банка этими изменениями не гарантируется.

Публичные документы не содержат ФИО владельца, ИП, ООО, ИНН и личных реквизитов. Email в форме поддержки — данные самого заявителя, не публичный контакт владельца.

Маркетинговые формулировки сайта заменены на описание подключения устройств и управления ими. Прежние рекламные слоганы удалены. Бот, Telegram-канал и иноязычные дубли не входят в этот репозиторий и здесь не изменялись. Описания тарифов приходят из backend: новые описания также нужно проверять перед публикацией, frontend не подменяет их и не фильтрует скрыто.

Backend при проверке вернул: Mini — 149 RUB / 30 дней / 1 устройство; Кукареку — 299 RUB / 30 дней / 3 устройства; Family — 499 RUB / 30 дней / 7 устройств. Это результат проверки, не резервные цены для UI. На сайте цены всегда берутся из API, показываются как полная стоимость периода вместе с количеством устройств и составом услуги.

## Работа поддержки

Пользователь отправляет обращение на `/support`, получает секретную ссылку `/support/ticket#id=…&key=…`, читает ответ и может дополнять обращение. Логин не требуется. Секрет находится во fragment URL (не уходит в HTTP URL и Referer); для доступа API передаётся в POST body, в SQLite хранится его SHA-256. Закрытая ссылка — ключ доступа, поэтому её нужно сохранить и не передавать другим. Email-уведомления не отправляются, восстановление утраченной ссылки по одному email не предусмотрено.

Хранилище: `SUPPORT_DB_PATH`, по умолчанию `./data/support.sqlite`, на постоянном диске. Каталог исключён из Git. Node.js ≥22.13 со встроенным `node:sqlite`; на Node 22 возможен ExperimentalWarning. Для production нужен постоянный том и одна пишущая инсталляция приложения/локальная файловая система; ephemeral/serverless storage не подходит. Резервное копирование базы настраивается на стороне хостинга.

Оператор работает на сервере приложения с доступом к этой базе:

```sh
npm run support -- list
npm run support -- read <ticket-id>
npm run support -- reply <ticket-id> /absolute/path/reply.txt
```

Файл ответа — UTF-8, 1–5000 символов. Команда ответа сразу сохраняет сообщение, видимое клиенту по его ссылке. Это локальный инструмент: публичного endpoint администратора нет. `SUPPORT_DB_PATH` для CLI и Next должен указывать на один файл. Если значение задано в `.env.local`, экспортируйте его при запуске CLI либо используйте `node --env-file=.env.local --experimental-strip-types scripts/support.mjs list`. Не публикуйте базу или CLI-вывод: они содержат данные обращений. Ответы не отправляются автоматически — оператор должен проверять список.

Создание: не более 5 обращений на email в час и 200 суммарно в час; сообщения — до 10 в минуту на тикет/сторону. Размер тела запросов ограничен, входные данные проверяются, доступ к чужому тикету без ключа отклоняется. Для публичного хостинга также настройте защиту от массовых запросов на reverse proxy. После 180 дней без сообщений тикет удаляется при следующем обращении к базе.

Название в публичных материалах: «Кукареку Онлайн». Старое изображение с прежней надписью перенесено из `public` в `assets/source/` и не раздаётся сайтом. В интерфейсе используется обновлённый логотип «Кукареку Онлайн» из `public/kukareku-online.png`. Раздел устройств: `/app/connections`. Формат скачиваемой конфигурации и коды ответов backend сохранены для совместимости. Название совместимого приложения можно уточнить через поддержку; публичная инструкция описывает импорт файла без марки приложения.
